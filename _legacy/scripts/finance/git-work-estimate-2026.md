This report estimates time spent across the sibling `parascene*` repositories
using Git commits authored by `crosshj` from January 1, 2026 through September
22, 2026.

Git does not record actual working time. This is an estimate of committed
development activity only; it excludes work done between commits, research,
debugging without a commit, meetings, and other non-committed work.

## Weekly estimate

Weeks begin on Monday. Dates and commit timestamps were grouped in UTC. The
estimated hours for each week use this simple rule for each active day:

- count at least 1 hour for a day with commits;
- otherwise use the time between the first and last commit that day;
- cap any single day at 6 hours.

## Interpretation

The earlier broad Git-only range of roughly **600–1,000 hours** remains more
honest than treating **930.8 hours** as exact. The weekly figures are useful
for showing the historical pattern of activity, but they should not be used as
an invoice or timesheet without corroborating records.
