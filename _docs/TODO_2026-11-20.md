# TODO: 2026-11-20 priority

The highest priority is Blue creation reliability, phase 0: stop accepted Blue jobs from dying in `queued` or `processing`.

A finished Blue image, video, or audio file can sit uncollected until Blue deletes it, about an hour later. The person already paid credits, and a `410` means the file is gone. Refunds and a second poll can also go wrong. The cost plan depends on Blue being the normal path and Replicate only the overflow. That shift makes this worse until collection is trustworthy. The lock-handoff and owner-read recovery are the part to ship now, on whichever worker actually runs the poll.
