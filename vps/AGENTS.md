# VPS agent instructions

Before changing VPS/Beta code, read [VPS/Beta migration guidance](../_docs/BETA_VPS_SPA_MIGRATION_SOURCE_OF_TRUTH.md). It owns the active WWW reference, deployment/build boundary, import adaptation and cutover requirements.

For client organization and lifecycle ownership, follow [VPS client architecture](../_docs/BETA_VPS_CLIENT_ARCHITECTURE.md).

Before mobile shell, navigation, composer or responsive layout work, read the
[mobile parity contract](../_docs/BETA_VPS_MOBILE_PARITY.md). It is currently a
discussion draft: use its source-mapping and verification requirements, and
resolve proposed product decisions with the user before the UI port.
